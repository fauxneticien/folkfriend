02

Transcribe PCM → contour string

Feed 1024-sample PCM windows into the WASM core. Internally: blackman window → FFT → autocorrelation-style feature (frames × 48 MIDI bins) → beam-search lattice path → octave-corrected contour.

Contour string

Each character encodes a MIDI pitch (a=C2 … V=B6). Capitals indicate held notes, lowercase indicates onsets; x = rest, others encode quavers/triplets.
